== Latex Notation Examples: Arrows

An example of a map from Cartesian coordinates (x, y) in R^2^ to polar coordinates (r, θ):

.The LaTeX code
[source,latex]
----
(x, y) \longmapsto (r, \theta)
----

Rendered:: latexmath:[(x, y) \longmapsto (r, \theta)]

=== Frequently used arrows

.The LaTeX code
[source,latex]
----
\mu \leftrightarrow \nu
\mu \longleftightarrow \nu
----

Rendered:: latexmath:[\mu \leftrightarrow \nu]
