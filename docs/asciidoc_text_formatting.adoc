== Text Formatting

=== 上付き文字、下付き文字、underline、overline

[cols="8h,20a,8a,10d" {table_options}]
|===
|              | Type         | See  | Notes

| italic          | pass:[_hello world_]   | _hello world_ |
| bold            | pass:[*hello world*]   | *hello world* |

| bold
| pass:[This +*literal*+ will appear as *literal*.]
footnote:[To exclude a phrase from substitutions, enclose it in plus signs (+).]
| This +*literal*+ will appear as *literal*.
|

| italic and bold | pass:[*_hello world_*] | *_hello world_* |
| code            | pass:[`hello world`]   | `hello world` |
| code and bold   | pass:[`*hello world*`] | `*hello world*` |
| code and italic and bold | pass:[`*_hello world_*`] | `*_hello world_*` |
| super script    | pass:[x^2^]     | x^2^  |
| subscript       | pass:[H~2~O]    | H~2~O |

| line-through |
....
[line-through]#word#
....
| [line-through]#word# |

| underline    |
....
This is [underline]#a pen#.
....
| This is a [underline]#pen#. |

| overline    |
....
[overline]#A#√[overline]#2#
....
| [overline]#A#√[overline]#2# | pdf not working

| big{bl} small |
....
[big]##a big apple## and [small]##a small cherry##
....
| [big]##a big apple## and [small]##a small cherry## | pdf not working

| aqua    |
....
This is [fuchsia]#a pen#.
....
| This is a [fuchsia]#pen#. | pdf not working
|===
